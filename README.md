# AP Gov Practice

Interactive AP Government & Politics practice platform with quizzes, amendments, articles, and more.

## Features
- Interactive practice quizzes
- Amendments flashcards
- Constitutional articles
- SCOTUS case studies
- Vocabulary drills
- Dark mode
- Progress tracking

## Local Development

```bash
npm run dev
```

Visit `http://localhost:3000` and open `AP Gov Practice Fixed.html`

## Deploy to Vercel

Connected via GitHub. Push to trigger automatic deploy.

```bash
git push origin main
```
